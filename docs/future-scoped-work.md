**what would trigger it** — so the backlog is a set of decisions rather than a wish list.

Nothing here is an oversight. Anything discovered mid-development that gets deferred
lands here in the same commit that decides to defer it.

Status: `deferred` (decided, not scheduled) · `blocked` (waiting on something named) ·
`spike` (needs investigation before it can be scoped).
